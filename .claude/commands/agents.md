# /agents

1. Read every persona in `.ai/shared/agents/` and `.ai/shared/workflows/operating-model.md`.
2. Present a table of the agents: icon, name, what they own, and when they run.
3. Explain the commands: `/feature <request>` (full pipeline), `/review <PR>` (review loop on any PR) and `/release [hotfix <name>]` (production, Gate G2). A task file in `docs/tasks/` can also be handed over directly.
4. Explain the two human gates (G1 plan, G2 production) and that every GitHub comment is signed by its agent.
