# Page index

One file per page, `<page>.md`, written by `/design` at gate D2. It is the only file agents read to know the current approved design of a page:

| Order | `data-section` | Current changeset | Lovable commit |
| ----- | -------------- | ----------------- | -------------- |

The approved commit of the whole page is recorded at the top: `Approved commit: <sha> (design/<page>-v<n>)`.
